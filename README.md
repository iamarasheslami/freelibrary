# FreeLibrary

> ⚠️ **Status: early development.** This project is being built from scratch following a
> phased roadmap. Architecture, features, and this README will expand as each phase lands.

A free, offline-first, privacy-respecting Android app for reading and downloading public-domain
books — built with low-resource devices and low-connectivity regions in mind.

## Goals

- 100% free, no ads, no in-app purchases, no subscriptions
- No accounts, no user profiles, no tracking or telemetry — a reading-position cache is the
  only local state kept, so you can pick up where you left off
- Works offline once a book is downloaded
- Runs smoothly on older, low-RAM Android devices (minSdk 21)
- Built to make adding additional free book-source APIs straightforward over time
